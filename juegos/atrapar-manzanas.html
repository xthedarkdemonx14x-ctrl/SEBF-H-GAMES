🍎 Atrapar Manzanas

📖 Historia del juego

Atrapar Manzanas nació como uno de mis primeros proyectos de desarrollo de videojuegos.

La idea comenzó como un juego sencillo, pero poco a poco fui agregando nuevas mecánicas, sonidos, obstáculos, puntos, vidas y diferentes elementos para hacerlo más divertido.

Este proyecto fue una de las primeras experiencias que tuve creando un videojuego desde cero.

🛠️ Herramientas utilizadas

🎮 Pocket Code

💡 Diseñado y desarrollado como proyecto independiente.

🎮 Sobre el juego

Atrapa las manzanas para conseguir puntos, evita las bombas y utiliza diferentes elementos para intentar conseguir la mejor puntuación. 🍎💣
